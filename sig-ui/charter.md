# SIG UI Charter

This charter adheres to the conventions described in the [Kubernetes Charter README] and uses the Roles and Organization Management outlined in [sig-governance].

## Scope

SIG UI covers GUI-related aspects of the Kubernetes project. Efforts are centered around Headlamp: an easy-to-use and extensible Kubernetes web UI. It allows users to manage applications running in the cluster and troubleshoot them, as well as manage the cluster itself.

#### Code, Binaries and Services

- [Headlamp](https://github.com/kubernetes-sigs/headlamp)

#### Cross-cutting and Externally Facing Processes

- Cutting new releases of Headlamp

### Out of Scope

Tools that contributors use in support of the project (eg. Prow, Test Grid)

## Roles and Organization Management

This SIG adheres to the Roles and Organization Management outlined in [sig-governance] and opts-in to updates and modifications to [sig-governance].

### Deviations from [sig-governance]

SIG UI's Chairs listed in [sigs.yaml] also serve as Technical Leads.

### Subproject Creation

SIG UI Chairs follow the Technical Leads process for subproject creation. See [Subproject creation].
